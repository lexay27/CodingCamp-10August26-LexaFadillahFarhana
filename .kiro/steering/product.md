# Product: To-Do List Life Dashboard

## What it is
A personal productivity dashboard that runs entirely in the browser — no server, no framework, no dependencies.

## Purpose
A CodingCamp mini project built to practice core web fundamentals: HTML structure, CSS styling, and vanilla JavaScript logic.

## Target user
The developer/student building and using it personally.

## Core sections
1. **Greeting** — shows a live clock, current date, and a time-based greeting personalised with the user's name.
2. **Focus Timer** — a Pomodoro-style countdown timer with start, stop, and reset controls and a configurable duration.
3. **To-Do List** — full task management: add, edit, mark complete, and delete tasks.
4. **Quick Links** — save and display favourite website links as clickable pills.

## Challenges implemented
- Light / Dark mode toggle
- Custom name in greeting
- Custom Pomodoro duration
